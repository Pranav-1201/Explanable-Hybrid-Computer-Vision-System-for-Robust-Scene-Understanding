    About & limitations

    This is a general 67-class indoor-scene model (ResNet-50 pretrained on Places365), rigorously benchmarked at 83.9% top-1 on a held-out test set. It was not purpose-built for real estate.

    It has been deliberately scoped into a focused property tool: predictions in a curated set of ~24 home and property room types are shown as tags, and everything else is routed to review as out of scope. Confidence is temperature-calibrated, and any photo below the calibrated threshold is also flagged.

    The scope is a scene-to-room map, not a residential-versus-commercial filter, so it has honest edges: an airport interior can be tagged Lobby / entryway, since lobby is in the set. Catching cases like that is exactly what the review queue is for — a human confirms, the model never pretends.
